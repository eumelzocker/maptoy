# maptoy

maptoy เป็นเครื่องมือแบบโฮสต์เองสำหรับดู เก็บประวัติ และส่งออกแผนที่แรสเตอร์
การตั้งค่าและข้อมูลแผนที่จะอยู่ภายใต้การควบคุมของคุณ

## ภาษาของเอกสาร

ภาษาอังกฤษเป็นภาษาอ้างอิงที่มีเนื้อหาครบถ้วน
หากหน้าใดยังไม่มีคำแปลภาษาเยอรมันหรือภาษาไทย
แอปจะแสดงหน้าอังกฤษพร้อมข้อความแจ้งให้ทราบอย่างชัดเจน
