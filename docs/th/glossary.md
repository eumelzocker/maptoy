# อภิธานศัพท์

อภิธานศัพท์นี้อธิบายแนวคิดเกี่ยวกับแผนที่และ maptoy
ส่วนคำย่อรวบรวมไว้ต่างหากใน[รายการคำย่อ](docs/th/abbreviations)

## Attribution

ข้อความหรือเครื่องหมายที่ระบุแหล่งข้อมูลและผู้ให้บริการภาพแผนที่ maptoy
จะแสดงข้อมูลที่มาที่กำหนดไว้บนแผนที่แบบโต้ตอบ
และรวมไว้ในการส่งออกเมื่อเกี่ยวข้อง

## Bounds

ขอบเขตภูมิศาสตร์รูปสี่เหลี่ยม ซึ่งมักระบุด้วยขอบด้านตะวันตก ใต้ ตะวันออก และเหนือ
ใน maptoy ขอบเขตนี้ใช้กำหนดพื้นที่ดาวน์โหลด พื้นที่ส่งออก
หรือตำแหน่งของชั้นข้อมูลภาพได้

## Cache

ที่จัดเก็บภายในเครื่องสำหรับไทล์ที่ดาวน์โหลดจากผู้ให้บริการแล้ว
ไทล์ในแคชนำกลับมาใช้ได้โดยไม่ต้องส่งคำขออีก
ทั้งนี้ขึ้นอยู่กับโหมดการรีเฟรชและรุ่นข้อมูลที่เลือก

## Cache snapshot

ชุดไทล์รุ่นที่เจาะจงสำหรับชุดแผนที่และรุ่นแหล่งข้อมูล
มีชื่อกำกับและแก้ไขไม่ได้ สแนปช็อตทำให้การแสดงผล
การเปรียบเทียบ และการส่งออกในภายหลังทำซ้ำได้

## Capability

ข้อมูลที่ระบบอ่านได้เพื่อระบุว่าผู้ให้บริการ อะแดปเตอร์เรนเดอร์
หรือปลั๊กอินชั้นข้อมูลรองรับความสามารถใด เช่น การแสดงผลแบบโต้ตอบ
การแคช การดาวน์โหลด หรือการส่งออก

## Content hash

ค่ารหัสย่อยเชิงเข้ารหัสที่คำนวณจากไบต์ซึ่งจัดเก็บไว้ maptoy
ใช้ค่านี้ตรวจหาเนื้อหาไทล์ที่เหมือนกันและระบุตำแหน่งไฟล์เนื้อหา
โดยไม่ทิ้งประวัติรุ่น

## Coordinate reference system

กฎที่ทำให้พิกัดอ้างถึงตำแหน่งบนโลกได้อย่างชัดเจน maptoy
ใช้รหัส EPSG ระบุระบบอ้างอิงพิกัดที่รองรับ

## Coverage

ข้อมูลสรุปว่าในพื้นที่และช่วงระดับการซูมหนึ่งมีไทล์ใดบ้าง
สถานะความครอบคลุมแยกเป็น มีแล้ว ขาดหาย ล้าสมัย
หรือกำลังดาวน์โหลด

## GeoJSON

รูปแบบข้อมูลที่ใช้ JSON เพื่อเก็บวัตถุทางภูมิศาสตร์และคุณสมบัติ
ปลั๊กอินชั้นข้อมูลแทร็กนำเข้าเรขาคณิตแบบเส้นและจุดที่รองรับจาก GeoJSON ได้

## Layer

ข้อมูลที่วาดทับบนแผนที่ฐาน ใน maptoy อินสแตนซ์ของชั้นข้อมูลอยู่ภายใต้การจัดการ
ของปลั๊กอินที่ลงทะเบียนไว้ และอาจมีแทร็ก ภาพที่ระบุตำแหน่ง
หรือข้อมูลชนิดอื่น

## Logical tile

ตัวตนของไทล์ภายในชุดแผนที่และรุ่นแหล่งข้อมูล
กำหนดด้วยระดับการซูมและพิกัด `x`/`y`
ไทล์เชิงตรรกะหนึ่งรายการมีไทล์หลายรุ่นที่แก้ไขไม่ได้

## Map Set

การตั้งค่า maptoy ที่รวมแหล่งแผนที่ อะแดปเตอร์เรนเดอร์ การแสดงผล
นโยบายแคชและดาวน์โหลด และชั้นข้อมูลที่กำหนดไว้
ค่าความลับจะอ้างอิงจากสภาพแวดล้อมและไม่ถูกเก็บในชุดแผนที่

## Provider

แหล่งภายนอกที่ maptoy ขอไทล์แผนที่ ผู้ใช้มีหน้าที่ตรวจสอบและปฏิบัติตาม
ข้อกำหนดปัจจุบัน เงื่อนไขการแสดงที่มา ขีดจำกัดทางเทคนิค
และรูปแบบการใช้งานที่อนุญาตของผู้ให้บริการ

## Renderer adapter

คอมโพเนนต์ที่เชื่อมอินเทอร์เฟซแผนที่กลางของ maptoy
เข้ากับตัวเรนเดอร์ในเบราว์เซอร์ เวอร์ชัน 1.0 มีอะแดปเตอร์ Leaflet/XYZ

## Reprojection

การแปลงข้อมูลภูมิศาสตร์หรือภาพแรสเตอร์จากระบบอ้างอิงพิกัดหนึ่งไปเป็นอีกระบบ
การแปลงนี้อาจเปลี่ยนรูปร่าง มาตราส่วน และขอบเขตที่มองเห็น

## Source revision

รุ่นที่แก้ไขไม่ได้ของฟิลด์ในชุดแผนที่ซึ่งมีผลต่อการขอไทล์ เช่น แม่แบบ URL
รูปแบบการแสดงผล ส่วนหัว ชนิดไฟล์ ขนาดไทล์ และระบบพิกัดของแหล่งข้อมูล

## Tile

ภาพแผนที่สี่เหลี่ยมขนาดเล็กที่ระดับการซูมและตำแหน่ง `x`/`y` หนึ่งตำแหน่ง
ไทล์ที่อยู่ติดกันประกอบเป็นแผนที่ที่เห็นในตัวเรนเดอร์หรือไฟล์ส่งออก

## Tile revision

ระเบียนเนื้อหาไทล์ที่พบ ณ เวลาหนึ่งและแก้ไขไม่ได้
ระเบียนนี้เก็บแฮชเนื้อหาและเมทาดาทาการตรวจสอบ
พร้อมรักษาเนื้อหาทั้งรุ่นก่อนหน้าและรุ่นถัดไป

## URL template

URL ของผู้ให้บริการที่มีตัวแทนค่า เช่น `{z}`, `{x}` และ `{y}` maptoy
จะแทนค่าตามไทล์ที่ร้องขอและจัดการการอ้างอิงค่าความลับที่กำหนดไว้
โดยไม่เก็บค่าจริงในชุดแผนที่

## Web Mercator

ระบบอ้างอิงพิกัดแบบฉายที่ใช้กันทั่วไปกับแผนที่แบบเลื่อนและไทล์ XYZ
มีรหัส `EPSG:3857` และมีความบิดเบือนของมาตราส่วนกับพื้นที่มากขึ้นเมื่อเข้าใกล้ขั้วโลก

## Zoom level

พิกัด `z` ในพีระมิดไทล์ XYZ ระดับการซูมที่สูงขึ้นมีจำนวนไทล์มากขึ้น
และโดยทั่วไปจะแสดงพื้นที่เล็กลงด้วยรายละเอียดมากขึ้น
