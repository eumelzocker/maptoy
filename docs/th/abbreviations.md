# รายการคำย่อ

รายการนี้รวบรวมคำย่อที่ใช้ใน *maptoy* และเอกสารประกอบ
ส่วนชื่อผลิตภัณฑ์และชื่อรูปแบบข้อมูลที่ไม่ใช่คำย่อมีคำอธิบายอยู่ใน
[อภิธานศัพท์](docs/th/glossary)

| คำย่อ | คำเต็ม | ความหมายใน *maptoy* |
| --- | --- | --- |
| ADR | Architecture Decision Record | บันทึกการตัดสินใจด้านสถาปัตยกรรมที่สำคัญพร้อมเหตุผล โดยจัดเก็บแบบมีเวอร์ชัน |
| API | Application Programming Interface | อินเทอร์เฟซ HTTP ที่เว็บแอปพลิเคชันและไคลเอนต์อื่นใช้ติดต่อกับ *maptoy* |
| CSP | Content Security Policy | นโยบายของเบราว์เซอร์ที่จำกัดแหล่งและทรัพยากรที่แอปพลิเคชันเรียกใช้ได้ |
| CRS | Coordinate Reference System | ระบบพิกัดพร้อมข้อมูลที่จำเป็นสำหรับระบุตำแหน่งพิกัดบนโลก |
| DD | Decimal Degrees | รูปแบบพิกัดที่แสดงละติจูดและลองจิจูดเป็นเลขทศนิยมมีเครื่องหมาย เช่น `53.548333°, 9.978889°` |
| DMM | Degrees and Decimal Minutes | รูปแบบพิกัดที่แสดงละติจูดและลองจิจูดเป็นองศาเต็มบวกลิปดาทศนิยม เช่น `53° 32.900'N 9°58.733'E` |
| DMS | Degrees, Minutes, and Seconds | รูปแบบพิกัดที่แสดงละติจูดและลองจิจูดเป็นองศาเต็ม ลิปดา และฟิลิปดา เช่น `53° 32'54.0"N 9°58'44.0"E` |
| DPI | Dots per inch | ข้อมูลกำกับความละเอียดของภาพแรสเตอร์ที่ส่งออก ค่านี้เพียงอย่างเดียวไม่ได้เพิ่มรายละเอียดของแผนที่ |
| EPSG | European Petroleum Survey Group | ที่มาของชื่อรหัสตัวเลขที่นิยมใช้ระบุระบบอ้างอิงพิกัด เช่น `EPSG:3857` |
| EXIF | Exchangeable image file format | ข้อมูลกำกับในไฟล์ภาพ ซึ่งอาจมีการวางแนว เวลาถ่าย และพิกัด GPS |
| GDAL | Geospatial Data Abstraction Library | เครื่องมือบรรทัดคำสั่งที่ *maptoy* ใช้แปลงระบบพิกัดของภาพแรสเตอร์ |
| GPS | Global Positioning System | ระบบระบุตำแหน่งด้วยดาวเทียม *maptoy* ใช้พิกัด GPS ที่อยู่ในภาพหรือแทร็กได้ |
| GPX | GPS Exchange Format | รูปแบบ XML สำหรับแลกเปลี่ยนแทร็ก เส้นทาง และจุดบอกตำแหน่ง |
| HTTP | Hypertext Transfer Protocol | โพรโทคอลที่ใช้กับ API ของ *maptoy* และคำขอไปยังผู้ให้บริการในกรณีที่อนุญาต |
| HTTPS | Hypertext Transfer Protocol Secure | HTTP ที่ป้องกันด้วยการเข้ารหัสระหว่างส่งข้อมูล และเป็นโพรโทคอลเริ่มต้นสำหรับผู้ให้บริการภายนอก |
| JPEG | Joint Photographic Experts Group | รูปแบบภาพแรสเตอร์แบบสูญเสียข้อมูลที่รองรับสำหรับการส่งออกแผนที่ |
| JSON | JavaScript Object Notation | รูปแบบข้อมูลมีโครงสร้างที่ใช้ใน API สคีมาการตั้งค่า และ GeoJSON |
| OGC | Open Geospatial Consortium | องค์กรมาตรฐานที่ดูแลมาตรฐานข้อมูลภูมิสารสนเทศ เช่น WMTS |
| PNG | Portable Network Graphics | รูปแบบภาพแรสเตอร์แบบไม่สูญเสียข้อมูลที่รองรับสำหรับไทล์และการส่งออกแผนที่ |
| SDK | Software Development Kit | ข้อตกลงแบบมีเวอร์ชันสำหรับพัฒนาอะแดปเตอร์เรนเดอร์และปลั๊กอินชั้นข้อมูล |
| SPA | Single-Page Application | แอปพลิเคชันในเบราว์เซอร์ที่แสดงส่วนติดต่อผู้ใช้และจัดการการนำทางฝั่งไคลเอนต์ |
| SQL | Structured Query Language | ภาษาที่ใช้สืบค้นฐานข้อมูลเมทาดาทา SQLite |
| SSRF | Server-Side Request Forgery | การโจมตีที่หลอกให้เซิร์ฟเวอร์ส่งคำขอไปยังทรัพยากรเครือข่ายที่ไม่ควรเข้าถึง |
| UI | User Interface | หน้าจอและตัวควบคุมในเบราว์เซอร์ที่ผู้ใช้โต้ตอบด้วย |
| URL | Uniform Resource Locator | ที่อยู่ของเส้นทางในแอป แหล่งไทล์ หรือเอกสารอ้างอิงภายนอก |
| WGS 84 | World Geodetic System 1984 | ระบบอ้างอิงเชิงภูมิมาตรที่ใช้รับค่าลองจิจูดและละติจูด มีรหัส `EPSG:4326` |
| WMTS | Web Map Tile Service | มาตรฐาน OGC สำหรับให้บริการไทล์แผนที่ โดยกรณีพิเศษของ WMTS ไม่อยู่ในขอบเขต *maptoy* v1.0 |
| XYZ | ไม่ใช่คำย่อ โดย `x`, `y` และ `z` คือพิกัดไทล์ | รูปแบบไทล์ที่ *maptoy* v1.0 ใช้ โดย `z` คือระดับการซูม และ `x` กับ `y` ใช้ระบุไทล์ |
