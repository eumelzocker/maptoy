# ชุดแผนที่

ชุดแผนที่ (Map Set) เชื่อมต่อแหล่งภาพแรสเตอร์แบบ XYZ เข้ากับตัวเรนเดอร์ของ
*maptoy* พร้อมกำหนดมุมมองเริ่มต้น ความสามารถทางเทคนิค นโยบายแคช
และขีดจำกัดการดาวน์โหลด ระบบจะไม่ตั้งค่าผู้ให้บริการสาธารณะให้โดยอัตโนมัติ
ก่อนเพิ่มแหล่งข้อมูล โปรดตรวจสอบข้อกำหนดปัจจุบัน กฎการแสดงที่มา ขีดจำกัดคำขอ
และสิทธิ์ในการส่งต่อหรือจัดเก็บข้อมูลของผู้ให้บริการ ดูภาพรวมทางเทคนิคได้ที่
[ผู้ให้บริการไทล์](docs/th/tile-providers)

## สร้างชุดแผนที่

เปิด **Map Sets** เลือก **New Map Set** แล้วกรอกข้อมูลสำคัญต่อไปนี้:

- **Name** คือชื่อที่ใช้แสดงภายในระบบ
- **XYZ URL template** ต้องเป็น URL แบบ HTTP หรือ HTTPS ที่มี `{z}`, `{x}` และ
  `{y}` ส่วน `{s}` เป็นตัวเลือกและต้องกำหนด subdomain อย่างน้อยหนึ่งรายการ
- **Attribution** จะแสดงในตัวเรนเดอร์แบบโต้ตอบ รองรับทั้งข้อความธรรมดาและ
  markup ลิงก์ที่เข้ากันได้กับ Leaflet เช่น `<a href="https://…">…</a>`
  ระบบจัดเก็บและแสดง markup โดยไม่แก้ไข ดังนั้นเฉพาะผู้ดูแลระบบเท่านั้นที่ควรแก้ไข
  การตั้งค่าชุดแผนที่
- **Provider terms URL**, **Terms last reviewed** และ **Notes** ใช้บันทึกสิ่งที่
  ตรวจสอบแล้ว แต่ไม่ถือเป็นการอนุมัติทางกฎหมายจาก *maptoy*
- **Minimum**, **maximum** และ **default zoom** ต้องตรงกับช่วงจริงของแหล่งข้อมูล
  โดยค่า zoom เริ่มต้นต้องอยู่ภายในช่วงดังกล่าว
- **Default longitude and latitude** กำหนดมุมมองแรก
- **Tile size** และ **format** ต้องตรงกับข้อมูลตอบกลับจากผู้ให้บริการ

ค่า zoom อธิบายพิกัด `{z}` ของผู้ให้บริการ ไทล์ขนาด 512 พิกเซลที่ zoom `z`
ของผู้ให้บริการจะแสดงที่ Leaflet zoom `z + 1` เพราะมีรายละเอียดเท่ากับไทล์ขนาด
256 พิกเซลในระดับนั้น *maptoy* ปรับค่าชดเชยนี้ให้อัตโนมัติ ส่วนพิกัด API และแคช
ยังคงใช้ zoom ของผู้ให้บริการ

การใช้งานปัจจุบันรองรับเฉพาะแหล่งข้อมูลชนิด `xyz-raster` ใน Web Mercator
(`EPSG:3857`) และตัวเรนเดอร์ `leaflet-xyz`

มุมมอง **Map** จะจดจำจุดศูนย์กลางและ zoom ร่วมไว้ใน local storage ของเบราว์เซอร์
เมื่อโหลดหน้าใหม่ ระบบจะคืนมุมมองเดิม และเมื่อสลับชุดแผนที่จะคงพื้นที่เดิมไว้
เพื่อให้เปรียบเทียบแหล่งข้อมูลได้โดยตรง หากชุดแผนที่ใหม่มีช่วง zoom แคบกว่า
*maptoy* จะปรับ zoom ร่วมไปยังค่าที่ใกล้ที่สุดภายในช่วงนั้น ระบบจะใช้มุมมองเริ่มต้น
ที่ตั้งค่าไว้เมื่อไม่มีค่าที่จัดเก็บไว้อย่างถูกต้อง

## เปรียบเทียบแผนที่

เปิด **Compare Maps** จาก **Display Options** หรือจากเมนูย่อย **Tools**
ในเมนูบริบทของแผนที่ แล้วเลือก Map Set สำหรับทุกพื้นที่ เมื่อรายการที่เลือก
เข้ากันได้ ให้เปิดใช้งานการเปรียบเทียบจากในกล่องโต้ตอบนั้น จากช่องทำเครื่องหมาย
**Compare Maps** ใน **Display Options** หรือจากเมนูย่อย **Options**
ในเมนูบริบท ช่องทำเครื่องหมายสำหรับเปิดใช้งานจะยังคงปิดใช้งานจนกว่าทุกพื้นที่
จะมี Map Set แบบโต้ตอบและ Map Set ที่เลือกมีช่วง zoom ภาพที่ใช้ร่วมกันได้

กล่องโต้ตอบกำหนดพื้นที่แผนที่สองหรือสี่ส่วน แต่ละส่วนเลือก Map Set ของตนเองได้
และสามารถเลือก Map Set เดียวกันซ้ำได้ ส่วนแรกเป็นส่วนหลักสำหรับการรีเซ็ต
การนำทางด้วยพิกัด และ **Tile Calculator** ขณะเปรียบเทียบ ระบบจะซ่อนตัวเลือก
Map Set ตามปกติและข้อมูลแผนที่ เพราะแต่ละส่วนมีป้ายชื่ออยู่บนแผนที่โดยตรง

เลือกโหมดแสดงผลได้สองแบบ:

- **Continuous area** วางแผนที่ขนาดเต็มซ้อนตรงกันแล้วตัดภาพตามตัวแบ่ง
  พื้นที่ภูมิศาสตร์ที่มองเห็นจึงต่อเนื่องข้ามเส้นแบ่งแต่ละเส้น โดยชุดแผนที่จะ
  เปลี่ยนตรงเส้นแบ่ง
- **Same center and scale** ให้แต่ละส่วนใช้พื้นที่ของตนเอง ทุกส่วนจะแสดง
  จุดศูนย์กลางทางภูมิศาสตร์และมาตราส่วนภาพเดียวกัน แม้จะเลื่อนตัวแบ่งแล้วก็ตาม

ลากตัวแบ่งแบบไร้ขอบเพื่อปรับขนาดแต่ละส่วน เมื่อโฟกัสตัวแบ่งแล้วสามารถใช้ปุ่มลูกศร
รวมถึง **Home** และ **End** ได้ การ pan หรือ zoom บนแผนที่ใดจะเลื่อนทุกแผนที่
พร้อมกันทันที ตัวควบคุม zoom ร่วมใช้ช่วง zoom ภาพที่ทุกชุดแผนที่รองรับร่วมกัน
และคำนึงถึงค่าชดเชย zoom ของแหล่งข้อมูลสำหรับไทล์ขนาด 256 และ 512 พิกเซลโดยอัตโนมัติ

โหมดเปรียบเทียบใช้ตัวควบคุม zoom และการแสดงพิกัดอย่างละหนึ่งชุด
พื้นที่แผนที่แต่ละส่วนจะแสดง Attribution ของแหล่งข้อมูลของตนเอง โดย
**Show Attribution** จะควบคุมทั้งหมดร่วมกัน Custom Layers ที่มองเห็นได้จะแสดงบน
แผนที่เปรียบเทียบทุกส่วนโดยใช้การตั้งค่าและสถานะการมองเห็นร่วมกัน ส่วนการตกแต่ง
ที่ขึ้นอยู่กับตัวเรนเดอร์ เช่น Tile Grid จะคำนวณแยกกันสำหรับแต่ละ Map Set
เบราว์เซอร์จะจัดเก็บโหมด จำนวนแผนที่ Map Set และตำแหน่งตัวแบ่งที่เลือกไว้
อินเทอร์เฟซเปรียบเทียบรุ่นแรกแสดงสถานะไทล์ปัจจุบัน ส่วนโมเดลแหล่งข้อมูลที่บันทึกไว้
เตรียมรองรับการเลือกสแนปช็อตและช่วงเวลาแยกสำหรับแต่ละส่วนในภายหลังแล้ว

## การตั้งค่าแหล่งข้อมูลหลังเริ่มแคช

เมื่อชุดแผนที่มี Tile Revision ที่แคชไว้รายการแรก *maptoy* จะล็อกฟิลด์ที่กำหนด
แหล่งข้อมูล ได้แก่ ชนิดแหล่งข้อมูล แม่แบบ URL request headers, subdomains,
ขนาดไทล์ รูปแบบไฟล์ และระบบพิกัดของแหล่งข้อมูล ส่วน metadata มุมมอง ช่วง zoom
ความสามารถ ตลอดจนนโยบายแคชหรือดาวน์โหลดยังคงแก้ไขได้

หากต้องการเปลี่ยนฟิลด์แหล่งข้อมูลที่ถูกล็อก ให้ทำสำเนาชุดแผนที่แล้วแก้ไขสำเนา
วิธีนี้ทำให้พิกัดที่แคชไว้ทุกพิกัดยังผูกกับแหล่งข้อมูลที่เข้าใจได้เพียงแหล่งเดียว
โดยไม่ต้องเก็บประวัติเวอร์ชันแหล่งข้อมูลแยกต่างหาก การเปลี่ยนค่าตัวแปรสภาพแวดล้อม
เช่น การหมุนเวียน API key ที่อ้างจาก header จะไม่เปลี่ยนชุดแผนที่ที่จัดเก็บไว้
และไม่ทำให้ไทล์ในแคชใช้การไม่ได้

ตัวแก้ไขจะแสดงการควบคุมแหล่งข้อมูลที่ล็อกไว้เป็น disabled และมีคำสั่ง
**Duplicate to change source** เซิร์ฟเวอร์บังคับใช้กฎเดียวกันกับไคลเอนต์ API

## ข้อมูลลับและ request headers

ห้ามวาง API key ลงในชุดแผนที่โดยตรง ให้กำหนดไว้ในสภาพแวดล้อมของเซิร์ฟเวอร์
แล้วอ้างชื่อจาก URL หรือ header:

```text
https://tiles.example.test/{z}/{x}/{y}.png?key=${MAPTOY_EXAMPLE_API_KEY}
Authorization: Bearer ${MAPTOY_EXAMPLE_API_KEY}
```

ยอมรับเฉพาะชื่อที่ขึ้นต้นด้วย `MAPTOY_*` และตัวแปรที่อ้างถึงต้องมีอยู่เมื่อบันทึก
ชุดแผนที่ SQLite จะเก็บข้อความอ้างอิง ไม่ใช่ค่าจริงที่แก้แล้ว ดังนั้นข้อมูลตอบกลับ
ของ API การวินิจฉัย และเว็บอินเทอร์เฟซจึงไม่จำเป็นต้องได้รับข้อมูลลับ

Request headers ใช้รูปแบบหนึ่งบรรทัดต่อหนึ่งรายการเป็น `Name: value`
ไม่อนุญาตให้กำหนด hop-by-hop headers, `Host`, `Cookie` และ `Content-Length`
หากผู้ให้บริการ redirect ไปยัง origin อื่น *maptoy* จะลบ headers ที่กำหนดไว้
ก่อนดำเนินการต่อ

## ทดสอบผู้ให้บริการ

บันทึกชุดแผนที่แล้วเลือก **Test tile** *maptoy* จะขอไทล์ซึ่งครอบคลุม
จุดศูนย์กลางเริ่มต้นที่ zoom เริ่มต้น และรายงาน:

- พิกัด XYZ และสถานะ HTTP ของผู้ให้บริการ
- content type ที่ปรับรูปแบบแล้ว
- ขนาดข้อมูลตอบกลับและระยะเวลา
- ข้อผิดพลาดที่ชัดเจนสำหรับ DNS, timeout, เครือข่าย, ขนาด, สถานะ
  หรือชนิดภาพที่ไม่รองรับ

การทดสอบรองรับภาพแรสเตอร์ PNG, JPEG และ WebP แต่ไม่ได้ให้สิทธิ์ใช้ผู้ให้บริการ
และไม่ได้เปิดความสามารถใดโดยอัตโนมัติ

## การป้องกันเครือข่าย

คำขอไปยังผู้ให้บริการอนุญาต HTTPS เป็นค่าเริ่มต้น ระบบจะปฏิเสธ localhost
ที่อยู่ private และ link-local ทั้งเมื่อกำหนดเป็น IP โดยตรงและหลังการแปลง DNS
รวมถึงตรวจสอบปลายทาง redirect ซ้ำอีกครั้ง เซิร์ฟเวอร์ไทล์ private ที่โฮสต์เอง
ต้องเปิดการตั้งค่าเซิร์ฟเวอร์ `MAPTOY_TILES_ALLOW_PRIVATE_HOSTS=true`
อย่างชัดเจน การตั้งค่านี้อนุญาต HTTP ด้วย จึงควรเปิดเฉพาะในเครือข่ายที่เชื่อถือได้

ข้อมูลตอบกลับจากผู้ให้บริการมี timeout และขีดจำกัดจำนวนไบต์ที่กำหนดค่าได้
ค่าเริ่มต้นคือ 10 วินาทีและ 10 MiB ต่อไทล์ กำหนดได้ด้วย
`MAPTOY_TILES_PROVIDER_TIMEOUT_MS` และ `MAPTOY_TILES_MAX_BYTES`

## ความสามารถและขอบเขตปัจจุบัน

สวิตช์ความสามารถอธิบายพฤติกรรมทางเทคนิค ไม่ใช่การอนุญาตจากผู้ให้บริการ
*maptoy* จะรวมค่าเหล่านี้กับความสามารถของตัวเรนเดอร์ที่เลือก หากปิดความสามารถ
แบบโต้ตอบ ชุดแผนที่จะไม่สามารถเปิดในมุมมอง **Map** ได้

ใน Phase 2 มุมมอง **Map** จะโหลดทุกไทล์ผ่าน endpoint แบบสัมพัทธ์ของ *maptoy*
`api/map-sets/:id/tiles/:z/:x/:y` เบราว์เซอร์จะไม่ได้รับ URL ภายนอกของผู้ให้บริการ
หรือข้อมูลลับที่แก้ค่าแล้ว Tile Revisions แบบถาวร โหมดรีเฟรช สแนปช็อต
และการเปรียบเทียบสถานะแคชอธิบายไว้ในเอกสาร [แคชไทล์](docs/th/tile-cache)
ชุดแผนที่ที่รองรับจะมีคำสั่ง **Download tiles** ซึ่งเปิดขั้นตอน Batch Download
ที่คำนึงถึงแคชในมุมมอง **Coverage**
