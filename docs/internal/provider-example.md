# Example provider decision

Status: accepted for the initial implementation
Last reviewed: 2026-08-24

## Decision

OpenTopoMap is maptoy's documented source for manual development, smoke checks,
screenshots, and demonstrations that need real raster tiles. It requires no account
or credentials and uses this XYZ template:

```text
https://tile.opentopomap.org/{z}/{x}/{y}.png
```

maptoy will not provide or require a separate local Tile server. Creating the
development Map Set remains an explicit user action so its attribution, capabilities,
limits, and review date stay visible rather than silently appearing as provider
defaults.

Automated tests and reproducible rendering fixtures do not access OpenTopoMap or any
other public Tile service. They continue to use generated bytes or an in-process fake
provider. This keeps CI deterministic and avoids turning routine test runs into
uncontrolled third-party traffic; the fake provider is test infrastructure, not a
standalone local Tile service.

## OpenTopoMap development profile

The published OpenTopoMap usage notes make the map available under CC-BY-SA with
attribution and provide public Tile endpoints. That makes low-volume, interactive
development use suitable for maptoy when the current terms and attribution are
observed. This record is technical guidance, not legal advice or a guarantee that
the service or its conditions will remain unchanged.

Suggested Map Set values:

- name: `OpenTopoMap Development`
- source type: `xyz-raster`
- URL template: `https://tile.opentopomap.org/{z}/{x}/{y}.png`
- format and Tile size: PNG, 256 pixels
- source projection: `EPSG:3857`
- credentials: none
- attribution:
  `Map data: © OpenStreetMap contributors, SRTM | Map style: © OpenTopoMap (CC-BY-SA)`
- terms URL: `https://opentopomap.org/about#verwendung`
- terms review date: the date on which the developer actually checks the linked
  usage notes
- batch download: disabled
- request rate and concurrency: deliberately low for manual development

Small, bounded requests may exercise maptoy's interactive view and revision cache.
The public endpoint is community infrastructure with no availability guarantee;
mass downloads, broad pre-seeding, load tests, or an assumption of unlimited archive
and export rights are outside this development profile. Contact the project before
larger use and recheck the current terms before changing those capabilities.

Official references:

- <https://opentopomap.org/about#verwendung>
- <https://wiki.openstreetmap.org/wiki/OpenTopoMap>
- <https://github.com/der-stefan/OpenTopoMap>

## OpenStreetMap Standard tiles

OpenStreetMap Standard remains documented for comparison but is not maptoy's
development example.

Official references:

- <https://operations.osmfoundation.org/policies/tiles/>
- <https://www.openstreetmap.org/copyright>

The service can be configured manually for modest interactive viewing only, but
maptoy does not suggest a capability combination that conflicts with its policy.
